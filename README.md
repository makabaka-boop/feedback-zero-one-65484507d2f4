# seg-infer：分段正态后端精确推断

给定观测 `y ~ N(mean · 1, s2·I)`（均值未知），本工具支持两种作业。

## 分段作业（默认，`mode` 缺省或 `mode="segment"`）

1. 把长度为 `n` 的序列精确划分为 `k` 个连续非空段，最小化各点相对段均值的
   平方和；平局取内部断点数组字典序最小者。
2. 基于最优分段前两段构造对比向量 `η`、统计量 `t = η' y`、方差
   `v = s2·η'η` 与残差 `z = y − η·t/(η'η)`。
3. 精确求出稳定性区域
   `V = {u : 对 y(u) = z + η·u/(η'η) 重新全局分段仍得到同一断点集合 S}`，
   输出最大不相交区间（按下界排序、标注开闭、相接无缺口则合并、无穷为 `null`）。
4. 计算截断正态条件 CDF `Fθ(t) = Pθ(T ≤ t | T ∈ V)`，输出双侧 p 值
   `p = min(1, 2·min(Fμ0(t), 1−Fμ0(t)))` 以及满足
   `α/2 ≤ Fθ(t) ≤ 1−α/2` 的全部 `θ`（闭区间；无解时为空数组）。

## 趋势作业（`mode="trend"`）

用于识别缓慢漂移中的斜率变化。以正有理数 `lambda` 替代 `k`，要求 `n ≥ 3`，
其余输入规则沿用。

1. 求唯一拟合 `x`，最小化
   `Σ(yᵢ−xᵢ)²/2 + lambda·Σ|xᵢ₋₁−2xᵢ+xᵢ₊₁|`，后一求和遍历内部点
   （二阶差分的 L1 趋势滤波；二次项强凸保证解唯一）。全部使用精确
   `fractions.Fraction` 运算：盒约束对偶 QP 用原始积极集法求解，再由
   `x = y − lambda·D' s` 恢复。
2. `S` 为拟合二阶差分非零的中心点零基下标，按升序输出。`S` 为空时仅返回
   `{"S": [], "status": "no_change"}`。
3. 否则取 `S` 首项 `j`，令 `η` 仅在 `j−1、j、j+1` 处取 `1、−2、1`、其余为
   零；`t、v、z` 与分段作业使用相同公式。
4. 精确求出
   `V = {u : 对 y(u) = z + η·u/(η'η) 重新趋势拟合后结点集合 S 恰不变}`
   （不固定二阶差分的符号）。固定积极集与结点符号后，KKT 条件是 `u` 的线性
   不等式，故有限端点全部是有理数：自由对偶变量约束为弱不等式（闭端点），
   结点符号一致性为严格不等式（开端点）；枚举 `S` 上全部 `2^|S|` 个符号模式
   并取区间并集，区间编码与精度规则沿用分段作业。
5. 用完整 `V` 计算与分段作业相同的 `p`、`theta`，并追加按输入顺序排列的
   约分有理数数组 `fit`（整数渲染为 JSON 整数，其余为 `"p/q"` 字符串）。

例：`y=[0,0,12]`、`lambda=1` 时 `fit=[-1,2,11]`、`S=[1]`、
`V=(-∞,-6)∪(6,∞)`，两端点均开；末值改为 `6`（阈值等号）时
`S=[]`、`status=no_change`。

## 精确性

- 分段、成本系数、区域边界全部使用 `fractions.Fraction` 精确有理数运算。
- 有限边界表示为约分有理数，或整系数一/二次多项式的不同实根（零基序号
  `0` 为较小根、`1` 为较大根），并带严格有理隔离括号；比较与符号判定均为
  精确代数运算，浮点仅用于最终概率计算。
- 正态 CDF 仅用标准库 `math.erf`；区域求交、反演二分全部自写。
- 概率绝对误差 ≤ 1e-8，置信界误差 ≤ 1e-6（随机测试实测反演残差 < 1e-9）。
- 趋势作业的拟合、对偶与区域端点同样全程使用 `Fraction` 精确运算，无浮点
  参与任何判定；浮点仅用于最终 `p`、`theta` 的概率计算。

## 输入

JSON 对象。`mode` 缺省时分段作业的成员固定为 `y、k、s2、mu0、alpha`；
`mode="trend"` 时以 `lambda` 替代 `k`：

- `mode`（可选）：仅接受字符串 `"segment"` 或 `"trend"`；
- `y`：长度为 `n` 的数组，分段作业要求 `n ≥ 2`，趋势作业要求 `n ≥ 3`，
  元素为整数或 `p/q` 字符串；
- `k`（仅分段作业）：2 到 n 的整数，禁止布尔类型；
- `lambda`（仅趋势作业）：严格正的整数或 `p/q` 字符串；
- `s2、mu0、alpha`：整数或 `p/q` 字符串（分子为整数、分母为正整数）；
- 要求 `s2 > 0`、`0 < alpha < 1`。

重复成员、未知成员、非法类型与越界值均被拒绝，错误信息给出字段路径与
零基下标（如 `$.y[2]`）。输出文件仅在全部计算成功后原子替换，失败时保留
旧文件。

## 用法

```bash
python -I run_inference.py input.json output.json
```

`-I` 隔离模式下入口脚本会自行定位同目录包，不依赖当前工作目录或站点包。

输出示例（`y=[0,1,0], k=2, s2=1, mu0=0, alpha=1/20`）：

```json
{
  "S": [1],
  "V": [
    {"lower": null, "upper": {"rational": "-1/2"}, "upper_open": false},
    {"lower": {"rational": "3/2"}, "upper": null, "lower_open": false}
  ],
  "p": 0.4883391341856589,
  "theta": [[-1.0820591888549704, 2.082059188854969]]
}
```

无理端点（仅分段作业可能出现）形如 `{"poly": [a, b, c], "root_index": 0}`，
表示 `a·x² + b·x + c = 0` 的第 `root_index` 个实根（升序、零基）。趋势作业
的有限端点恒为有理数 `{"rational": "p/q"}`。趋势作业在有结点时额外输出
`fit`（按输入顺序的约分有理数数组）；无斜率变化时仅输出
`{"S": [], "status": "no_change"}`。
